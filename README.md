# TeamForge
Production-oriented hackathon team formation for 10,000 participants and 2,000 teams.

M1-A foundation: Spring Boot backend, PostgreSQL/Flyway, and React/TypeScript/Vite landing page with a real health client. Authentication and team workflows are not implemented.
Start with [progress](docs/progress.md), [requirements](docs/requirements.md), and [decisions](docs/decisions.md).
M0 is complete. M1-A source is present; prior frontend checks passed; local PostgreSQL/Flyway and all five backend tests now pass on Java 24. Packaging, Java 21 and fresh-terminal/proxy verification remain blocked. M1-B has not started.
